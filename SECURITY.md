# Security Policy

## Scope

mini-bank-api is a personal project, not a production system. It has no
authentication or authorization by design, so missing access control is
out of scope. Reports about money handling (precision, concurrency,
double spending, idempotency) or about the code and its dependencies are welcome.

## Supported Versions

Only the latest commit on `main` is supported. There are no releases.

## Reporting a Vulnerability

Open an [issue](https://github.com/assynu/mini-bank-api/issues) with steps
to reproduce. Since this is not a production system, public reports are fine.
